Rules

Credits

Credits are used to unlock token analysis.

How to Earn Credits

ActionCredits
Create your account+10
Connect a new exchange account+10
Create a privacy proof+1
Invite a new user who signs up+5 each
Invited user connects their first exchange+20 each
Invited user creates their first privacy proof+10 each
Buy credits1 USDC = 1 credit

Credit Rules

  • Credits do not expire.
  • There is no maximum credit balance.
  • You can earn unlimited credits from privacy proofs.
  • Each exchange connection reward can only be earned once per exchange.
  • Each account can connect up to 10 exchanges.

Points

Points measure your long-term contribution and reputation inside Insider.Cash.

How to Earn Points

ActionPoints
Connect a new exchange account+300
Create a privacy proof+10
Invite a new user who signs up+100 each
Invited user connects their first exchange+300 each
Invited user creates their first privacy proof+100 each

Point Rules

  • Points cannot be purchased.
  • Points cannot be directly converted into credits.
  • Points are not used to buy analysis.
  • You can earn up to 100 points per day from privacy proofs.
  • After reaching the daily proof point limit, you can still earn credits from privacy proofs.

Points may be used for reputation levels, public profiles, leaderboards, and future rewards.

Token Analysis Plans

Use credits to unlock token analysis in My Token.

PlanCostAccess PeriodAnalysis Coverage
Daily10 credits1 day + 1 extra dayRecent 3-day analysis
Extended100 credits2 weeks + 1 extra dayRecent 3-day analysis
Pro1000 credits1 month + 1 extra dayPast 1 month + next 1 month analysis

Analysis Rules

  • You can unlock up to 2 tokens per day.
  • Daily, Extended, and Pro each count as 1 token unlock.
  • There is no daily credit spending limit.
  • Token analysis is not permanent.
  • After access expires, you need to unlock it again.
  • Analysis may take up to 12 hours to become available.
  • We add 1 extra day to every plan so you always have enough time to view it.

Upgrades

You can upgrade a token plan at any time.

UpgradeCost
Daily to Extended100 credits
Daily to Pro1000 credits
Extended to Pro1000 credits

Upgrade rules:

  • Upgrades start a new access period.
  • Previously spent credits are not refunded.
  • Previously spent credits are not deducted from the upgrade price.
  • Upgraded plans also receive the extra 1-day access buffer.
